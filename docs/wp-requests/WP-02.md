Verified and revised by the WP-02 verifier on 2026-10-26. Every font fallback that is still left on the built pages
comes from CSS in files WP-02 does not own (R10–R13). Each fix below was checked by injecting the proposed CSS into
the built pages: the per-character font probe then reports zero system-font glyphs for the affected elements.

## R1 · WP-00/WP-11: tune `Plex Fallback` in `src/styles/type.css`
Measured with `scripts/fonts/plex-fallback.mjs` (Chromium; Arial has the same metrics as Liberation Sans) on the en
cover takeaway, the role line and the three summary paragraphs. Replace the placeholder descriptors with

```css
size-adjust: 100.86%; ascent-override: 101.63%; descent-override: 27.27%; line-gap-override: 0%;
```
Result: paragraph heights do not change on swap (0.0 % reflow on all six); single-line widths stay within 0.4 %.
The rule cannot go in `public/fonts/fonts-en.css`, because the main CSS bundle is linked after the font CSS and the
`type.css` copy would win.

## R9 · WP-11: after content freeze
1. Run `npm run fonts`. It re-subsets every face from the final copy, narrows each `&text=` subset's unicode-range to
   the glyphs its cmap really has, writes `missing` per face into `report.json`, and deletes stale files.
2. Run the checks under the browser lock:
   - `flock .locks/browser.lock node scripts/fonts/check-fonts.mjs specimen build/qa/fonts`
   - `flock .locks/browser.lock node scripts/fonts/check-fonts.mjs pages http://127.0.0.1:41xx/` on `vite preview`

   The pages check reports every element drawn by a system font. Fix it in the CSS stack (R10–R13), or add glyphs to
   the section's `strings.ts` `display[lang]` or to the face's sources in `scripts/fonts/faces.mjs`.
3. If the name, role or titles change, run `flock .locks/browser.lock node scripts/images/og.mjs`.
4. **Budget note for `build/budgets.json`.** The §10.1 limit "display subsets ≤ 50 KB (CJK) per language" cannot be met
   while §3.3 sets long texts in display faces: principle bodies, banzuke, quotes, the letter, essay titles. That is
   about 200 CJK glyphs in total. Measured CJK display subsets:

   | Language | Display subsets | Per face |
   |---|---|---|
   | ja | 379 KB | 9–51 KB |
   | zh | 352 KB | 7–79 KB |
   | en | 18 KB | |

   What changed in this pass:
   - The **preload is the cover name only**: ja 2.4 KB, zh 1.8 KB, en 52 KB (Bodoni Moda italic, Latin).
   - The language-wheel names (日本語 / 简体中文) are now a 2 KB file of their own. They used to pull a 49 KB foreign

   - **en Latin display is now 212 KB (≤ 220 KB).** The full variable ranges measured 657 KB. Axes are pinned to the

## R10 · WP-00/WP-11: CJK and symbols inside en copy (`src/styles/type.css`)
en copy contains CJK without `lang` (朱文 / 白文 in `.achievements__legend`, glossary terms) and `∝`. IBM Plex Sans has
none of these, so they fall back to system fonts. `fonts-en.css` already carries foreign subsets for exactly these
characters, cut to what each face has. Change the stack to

```css
--f-body-en: "IBM Plex Sans", "IBM Plex Sans JP", "Noto Sans SC", "Plex Fallback", Arial, sans-serif;
```
Latin text is unaffected: the CJK faces' unicode-ranges contain no Latin, so swap metrics still come from Plex
Fallback. Verified: 朱文, 白文 and ∝ are then drawn by IBM Plex Sans JP.

## R11 · WP-00/WP-11: web serif ahead of system serifs for zh (`src/styles/type.css`)
```css
--f-serif-zh: "Noto Serif SC", "Songti SC", "SimSun", serif;
```
The zh brush and poster faces (Zhi Mang Xing, Long Cang, Ma Shan Zheng, ZCOOL) lack `·` and a few punctuation marks.
With this stack those glyphs come from the Noto Serif SC subsets, which carry the zh punctuation, instead of a system
serif. Verified on `cite.quote__name` and `figcaption.quote__sig`.

## R12 · WP-00 (or WP-05 / WP-09): `--f-mono` has no CJK face
`.result__num` (WP-05) and `.seal-cap__value` (WP-09) are set in `var(--f-mono)` but contain CJK (毎秒, イベント,
毫秒, 个事件), which fall back to the system font. Either use `var(--f-chrome)` there (§3.3: chrome = Martian Mono +
body face for CJK), or have WP-00 add
`:lang(ja) { --f-mono: "Martian Mono", "IBM Plex Sans JP", ui-monospace, monospace; }` and the zh twin with
"Noto Sans SC". Verified: either way the readouts draw Martian Mono for the digits and the body face for the CJK.
