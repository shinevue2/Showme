# WP-05 requests (cover, summary, carve, peel): input for WP-11

Everything in `src/sections/{cover,summary}/**`, `src/gl/carve/**`, `src/gl/chunks/peel.ts` and
`public/img/posters/cover-*` is implemented (DESIGN §6.1, §6.2, bands `cover-summary`, `summary-road`).
Nothing here blocks a build.

## R1 · WP-00 / WP-11: `--f-mono` has no CJK face (same as WP-02 R12)
`.result__num` is set in `var(--f-chrome)` (Martian Mono + body face), so the summary readouts are fine. The cover's
`.jst-clock` and the summary's `.overlap__hours` use `var(--f-mono)` with digits only. Adding
`:lang(ja) { --f-mono: "Martian Mono", "IBM Plex Sans JP", ui-monospace, monospace; }` (+ zh twin with Noto Sans SC)
would still help other sections.

## R2 · WP-11: posters for `cover-block`
The cover has **no generic view poster**: its placeholder spans the whole artboard and runs into the summary (for the
block flip), so a poster there would be wrong. `render.ts` strips the `data-poster-*` attributes and inline poster
from the placeholder. The fallbacks are the DOM sheet (always) and the carved-block stills
`public/img/posters/cover-block-carved-{ja,en,zh}-{day,night}.avif` (per language: the name is carved in the block).
Please skip `cover-block` in `npm run capture:posters`. To re-capture the stills after a copy or font change:
`?poster=cover-block&theme=day|night&tier=medium` renders the bare block under raking light and writes its rect to
`#cover[data-capture-rect]`; crop that rect with a transparent background (1440 × 900, DPR 1.25, AVIF q 48).

## R3 · WP-11: stage measurement for sticky placeholders (WP-07 R1)
Not needed for `cover-block`: its placeholder is an absolute direct child of the artboard (not inside the sticky
stage), and the view computes its own off-axis frustum from the placeholder's document rect each frame.

## R4 · WP-11 (fonts)
Cover and summary display strings are all in `copy.*` / `facts.*` (no extra `display` glyphs). The carve redraws the
sheet with the loaded faces (`document.fonts.load` first), so the cover subsets must keep the name, ruby, role and
station names in the same faces as the DOM.

## R5 · WP-11 (CSS budget)
Cover `style.css` ≈ 3.5 KB gzip, summary ≈ 2.3 KB gzip. No further cuts without losing the CSS-peel fallback.
