## R3 · WP-10: notes on `createSealStone` (src/gl/seal)
- The signature is unchanged from §13.2. Frame: y is up, the paper is y = 0, the stone stands on it, and the face is
  at y = 0 facing −y. `press(t)` animates an inner pivot only, so you can place, rotate and scale `group` freely.
  The contact shadow is a child of `group`.
- Add `impression().quad` to your scene at the stone's x/z. It stays empty until `press()` passes 0.45 (contact),
  then stays. `impression().texture` is in reading orientation: rgb is the seal colour, a is ink coverage.
- WP-02's `seal-paths.json` `minato` works as is: `face: { svgPaths: [face, ...glyph], viewBox: [0, 0, 82, 100] }`,
  `style: 'hakubun'`. When the first path covers the face, it is read as the raised field. The stone takes the face's
  aspect (0.82 × 1).
- Extras on the returned object (optional): `ready` (a Promise that resolves when the face is carved and the
  impression drawn), `jitter` (radians; pass it to `ctx.print.setSeal({ rotation })`), `setSealColor()` (call it on
  theme change with `--seal`), and `light.dir` / `light.up` (world space; the default is y-up).
- Optional `SealOptions` fields: `showFace` (default true: the face is carved at `res`), `shadow` (default true) and
  `seed`.
