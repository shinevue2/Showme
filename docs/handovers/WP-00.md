## Deviations you should know about
1. **Sticky stages are lifted above the canvas.** §8.7 assumes a sticky stage stays "z-index: auto", but `position: sticky` always forms a stacking context, which hid text under the canvas. Sticky stages are now `z-index: 2` and must stay transparent where the 3D shows through. DOM that has to sit *behind* a view goes inside a `.view` placeholder that is a direct child of the artboard (`viewSlot(..., { inner })`). This means Principles' faint mist figure can't sit behind the garden inside its sticky stage; WP-08 needs to handle that.
2. **ScrollTrigger runs without two idle timers.** As shipped, it keeps a permanent rAF loop and a 250 ms interval that also requests rAF, which makes zero-rAF idle impossible. Both are switched off when it registers (`src/core/motion-chunk.ts`). It still updates on scroll and from Lenis. GSAP's own ticker is driven by the one clock (`core/frame.ts`).

## Other decisions
- **Content per language:** in the build, each language gets its own content bundle with the other two languages' strings blanked (names and site title keep all three). Runtime code must read `ctx.content` and never import `src/content` directly; WP-01 should know this.
- **Posters:** URLs are stored in `data-poster-*` attributes and turned into absolute `--poster-*` values at runtime. Relative `url()` inside CSS variables resolved against the stylesheet, not the page.
- **`:lang()` font fix:** the verbatim CJK rules reset the font on every nested element (the cover ruby rendered in the body face). I added an inheritance rule at the same specificity right after them.
- **Pins:** all §8.2 pins exist. TypeScript is 7.0.2; `@types/node` 26.6.5 was added for `vite.config.ts` and the SSG plugin; esbuild's install script was approved.
- **Chunking:** chunk groups use Rolldown's `codeSplitting.groups`, because `manualChunks` is deprecated in Vite 8.

- **Grain tiles**: `/img/gen/grain-*-256.webp` is requested from the server root until WP-02 adds the files. I confirmed in a scratch build that once the file exists Vite rewrites it to `../img/gen/…`, and postbuild warns until then.
- **Tool names**: `Tool.name` is a single string in Appendix A, so names like "Web performance" stay English on ja/zh pages. Localising them needs a type change (WP-11 decision).
- **Content bundles**: other languages' prose is still blanked at runtime; only the listed names are kept. Dev serves full content, so a cross-language read only shows up as broken in a build.
