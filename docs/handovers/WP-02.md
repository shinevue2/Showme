## Deviations
1. **Body CJK fonts:** instead of Google's unicode-range slices I generate our own `&text=` slices, with the first-view characters first. Google's slices put the ja cover text in 28 files (268 KB) and zh in 17 files (941 KB). Now: ja body 307 KB in 7 files per weight, zh about 500 KB. Weight 700 is a subset; Noto Serif SC is static weights 300/400/900, because the variable version's slices are 70–85 KB each.
2. **Shared CSS also carries:** the Latin display faces, a small extra subset for symbols Google's Latin slices leave out (→, ×, ≈), and on en/zh pages small subsets for cross-language text (the ja name, 大尾, language names).
3. **Crest orientation:** the triangle points down (▽), because pointing up read as an "A" logo.
4. **Seal shape:** 82 × 100 single-character rectangle, not square.
5. **Stencil threshold:** L* ≥ 60, applied at the source resolution so thin cuts survive.

## Fixes made

**Byōbu**
1. **Crops:** edge-brightness profiles showed brocade bands inside panels 1–4 and 6, and a hinge seam inside panel 5. All boxes are now at least 3 px clear of seams and borders.
2. **Signature:** Mitsumochi's signature had survived as dark specks; it is now erased from the alpha.
3. **Mobile panels:** they spanned 2–3 screen folds with seams, frames and the signature, at five different sizes. They are now single-fold crops, all 560 × 896.
4. **Atlas size:** 994 KB → 508 KB (3072) and 411 → 297 KB (1536), with no visible difference in a side-by-side check.

**Fonts**

5. **Unicode ranges:** Google lists every requested character in a subset's unicode-range, even ones the font lacks. A new dependency-free reader (`scripts/fonts/woff2-cmap.mjs`) trims each range to the glyphs the file really has, and `report.json` now lists what each face is missing.
6. **Preload:** it now carries only the cover name: ja 23.6 → 2.4 KB, zh 34 → 1.8 KB. The language-switch labels (日本語 / 简体中文) used to pull a 49 KB file into every page; they are now a 2 KB file of their own.
7. **en Latin display:** 657 → 212 KB, under the §10.1 limit of 220 KB. I pinned each face to the axis values §3.3 uses (Schibsted 700, Big Shoulders 700/opsz 72, Bricolage wdth 75/opsz 96/700, Newsreader 300/opsz 72 and italic 400/opsz 24). Display faces swap the latin-ext slice for a 1–4 KB supplement, restricted to the requested characters so kerning isn't broken.
   - Total font transfer on the en page: 926 → 430 KB.
   - This deviates from the spec's literal family specs. If another WP sets one of these faces at an unlisted weight, the browser uses the nearest one.

**Generated graphics**

8. **Today's print:** key lines no longer run through the cartouche. Gold is now drawn normally on top instead of multiplied (it turned olive over the green), and the round-capped bars became tapered bands.
9. **Favicon:** the 32 px PNG was invisible on dark browser tabs; it now has a paper disc behind the mark.
10. **Textures:** gold leaf lost its repeating diagonal streaks. The washi and night-grain fibres no longer look like hair arcs.
11. **Seal:** strokes go from 4.1 to 4.7 units so the cut lines hold at 56 px. The one stroke junction matches the Commons reference I fetched.

The crest follows the §6.1 numbers exactly and reads cleanly at 64–128 px. The small offcuts at each crossing come from the spec's 0.18 R extension, so I left the geometry unchanged.
